# What to Say in Interviews

- This is a real-world churn prediction pipeline built from a Kaggle dataset.
- I focused on clean preprocessing, strong baseline modeling, and clear metrics.
- I used logistic regression for interpretability and fast iteration.
- I measured ROC-AUC and average precision because churn is imbalanced.
- I export feature coefficients to explain why the model predicts churn.
- Next steps would be CV, model comparison, and threshold optimization.
